
# HB Transportes - MVP

## Sobre o projeto

Sistema web para controle de coletas, entregas e ocorrências logísticas, desenvolvido como projeto acadêmico da disciplina Projeto de Software da Universidade Cruzeiro do Sul.

O MVP tem como objetivo centralizar as informações operacionais da HB Transportes e Logística EIRELI, facilitando o acompanhamento das entregas, a atualização de situações e o registro de movimentações.

## Problema identificado

O acompanhamento de coletas e entregas por planilhas e mensagens pode provocar atrasos na atualização das informações, falhas de comunicação e retrabalho.

## Funcionalidades previstas

- Autenticação de usuários.
- Cadastro de clientes, motoristas e veículos.
- Cadastro de coletas e entregas.
- Consulta de entregas.
- Atualização da situação das entregas.
- Registro de ocorrências.
- Histórico de movimentações.

## Tecnologias selecionadas

- Python 3.12
- Django 5.2 LTS
- PostgreSQL
- HTML5
- CSS3
- JavaScript

## Arquitetura

Aplicação web monolítica em camadas, utilizando a estrutura MVT do Django, com separação entre apresentação, regras de negócio e persistência de dados.

## Segurança e acessibilidade

O projeto prevê autenticação, controle de permissões, validação de dados no servidor, consultas seguras e proteção de informações sensíveis.

A interface será responsiva, com rótulos claros, contraste adequado, navegação por teclado e mensagens compreensíveis.

## Objetivo de Desenvolvimento Sustentável

ODS 9 - Indústria, Inovação e Infraestrutura.

O projeto busca contribuir para a modernização e organização dos processos logísticos por meio de uma solução digital acessível.

## Status do projeto

Em desenvolvimento. As funcionalidades descritas representam o escopo planejado do MVP.
